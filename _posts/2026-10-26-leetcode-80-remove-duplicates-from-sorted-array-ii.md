문제 링크: [80. Remove Duplicates from Sorted Array II](https://leetcode.com/problems/remove-duplicates-from-sorted-array-ii/?envType=study-plan-v2&envId=top-interview-150)

## 문제 해석

감소하지 않는 순서로 정렬된 정수 배열 `nums`가 주어진다. 각 숫자가 최대 두 번만 나타나도록 중복을 제거하되, 원소의 상대적인 순서를 유지해야 한다.

중복을 제거한 결과의 원소 개수를 `k`라고 하면, `nums`의 처음 `k`칸에 결과를 저장하고 `k`를 반환한다. `k` 이후의 값은 무엇이든 상관없다.

추가 배열을 만들지 않고 입력 배열을 직접 수정해야 하며, 추가 공간은 `O(1)`이어야 한다.

## 풀이 방법

**두 포인터**를 사용하면 추가 배열 없이 해결할 수 있다. `k`를 **다음 숫자를 저장할 위치**이자 **지금까지 저장한 숫자의 개수**로 사용한다.

배열을 순회하면서 현재 숫자를 다음 조건일 때만 저장한다.

- `k < 2`: 아직 두 개도 저장하지 않았으므로 그대로 저장한다.
- `nums[k - 2] != num`: 저장된 결과의 뒤에서 두 번째 숫자와 다르면 저장한다.

배열이 정렬되어 있으므로, 현재 숫자가 `nums[k - 2]`와 같다면 이미 그 숫자를 두 번 저장한 상태다. 저장된 결과도 정렬되어 있으므로 마지막 숫자 역시 현재 숫자와 같기 때문이다.

여기서 비교 대상은 원본 배열에서 두 칸 앞의 값이 아니라, **저장된 결과의 뒤에서 두 번째 값**이다.

## Java 코드

```java
class Solution {
    public int removeDuplicates(int[] nums) {
        int k = 0;

        for (int num : nums) {
            if (k < 2 || nums[k - 2] != num) {
                nums[k] = num;
                k++;
            }
        }

        return k;
    }
}
```

`||`는 왼쪽 조건이 참이면 오른쪽 조건을 평가하지 않는다. 따라서 `k < 2`일 때는 `nums[k - 2]`에 접근하지 않는다.

## 동작 예시

`nums = [1, 1, 1, 2, 2, 3]`이면 다음처럼 진행된다. 표의 결과는 배열 전체가 아니라 앞 `k`칸에 저장한 유효한 부분이다.

| 현재 숫자 | 판단 | 저장된 결과 |
| --- | --- | --- |
| 1 | `k < 2`이므로 저장 | `[1]` |
| 1 | `k < 2`이므로 저장 | `[1, 1]` |
| 1 | `nums[k - 2] == 1`이므로 건너뜀 | `[1, 1]` |
| 2 | `nums[k - 2] != 2`이므로 저장 | `[1, 1, 2]` |
| 2 | `nums[k - 2] != 2`이므로 저장 | `[1, 1, 2, 2]` |
| 3 | `nums[k - 2] != 3`이므로 저장 | `[1, 1, 2, 2, 3]` |

최종적으로 `k = 5`를 반환한다. 배열의 앞 다섯 칸은 `[1, 1, 2, 2, 3]`이고, 이후의 값은 검사하지 않는다.

두 번째 예시인 `[0, 0, 1, 1, 1, 1, 2, 3, 3]`에서는 세 번째와 네 번째 `1`을 건너뛴다. 앞 일곱 칸에 `[0, 0, 1, 1, 2, 3, 3]`을 저장하고 `7`을 반환한다.

## 순회 중 배열을 수정해도 되는 이유

배열을 수정해도 안전한 이유는 **저장 위치가 현재 읽는 위치보다 앞서 나가지 않기 때문**이다.

현재 읽는 위치를 `i`라고 하면, 그전에 처리한 원소는 `i`개이므로 저장한 원소 개수 `k`는 항상 `i` 이하이다. 따라서 `nums[k]`에 값을 쓰더라도 현재 위치 또는 이미 읽은 위치만 수정한다. 아직 읽지 않은 원소를 덮어쓰지 않는다.

숫자를 앞에서부터 순서대로 읽고 저장하므로 원소의 상대적인 순서도 유지된다.

## 시간 및 공간 복잡도

- 시간 복잡도: **`O(n)`** — 배열을 한 번 순회한다.
- 추가 공간 복잡도: **`O(1)`** — 추가 배열 없이 변수만 사용한다.
